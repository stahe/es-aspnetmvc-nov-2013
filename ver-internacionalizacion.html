    6. Ver Internacionalización

    Aquí abordaremos la cuestión de la internacionalización de la vista. Se trata de una cuestión compleja, y puede encontrarse una buena descripción de la misma en el siguiente artículo de Scott Hanselman:

    [http://www.hanselman.com/blog/GlobalizationInternationalizationAndLocalizationInASPNETMVC3JavaScriptAndJQueryPart1.aspx]

    En primer lugar, repasemos sus definiciones de los diversos términos relacionados con la internacionalización de la visión:

    Internacionalización (i18n)
    hacer que la aplicación admita diferentes idiomas y configuraciones regionales
    Localización (l10n)
    hacer que la aplicación sea compatible con un par específico de idiomas/localidades
    Globalización
    la combinación de Internacionalización y Localización
    Idioma
    lengua hablada - designada por un código ISO (fr: francés, es: español, en: inglés, ...)
    Local
    una variante de la lengua - también designada por un código ISO (en_GB: inglés británico, en_US: inglés americano, ...)

    Abordemos el problema con un primer ejemplo.

    6.2. Gestionar una cultura

    El idioma de las vistas está controlado por el [Thread.CurrentThread.CurrentUICulture] objeto. Para mostrar páginas en la cultura [fr-FR], escribimos:

    Thread.CurrentThread.CurrentUICulture = new CultureInfo("fr-FR");

    La localización (fechas, números, monedas, horas, etc.) está controlada por el objeto [Thread.CurrentThread.CurrentCulture]. Similar a lo escrito anteriormente, escribimos:

    Thread.CurrentThread.CurrentCulture = new CultureInfo("fr-FR");

    Estas dos sentencias podrían colocarse en el constructor de cada controlador de la aplicación. Sin embargo, también podríamos querer factorizar este código que es común a todos los controladores. Tomaremos este enfoque.

    Creamos dos nuevos controladores:

    • [I18NController] será la clase base para todos los controladores que utilicen la internacionalización;
    • [SecondController] es un controlador de ejemplo derivado de [I18NController].

    El código del controlador [I18NController] es el siguiente:

    
using System.Threading;
using System.Web;
using System.Web.Mvc;
 
namespace Examples.Controllers
{
  public abstract class I18NController : Controller
  {
    public I18NController()
    {
      // retrieve the context of the current request
      HttpContext httpContext = HttpContext.Current;
      // check the request for the [lang] parameter
      // look for it in the URL parameters
      string language = httpContext.Request.QueryString["lang"];
      if (language == null)
      {
        // search for it in the posted parameters
        language = httpContext.Request.Form["lang"];
      }
      if (language == null)
      {
        // look for it in the user's session
        language = httpContext.Session["lang"] as string;
      }
      if (language == null)
      {
        // First parameter of the HTTP AcceptLanguages header
        language = httpContext.Request.UserLanguages[0];
      }
      if (language == null)
      {
        // culture fr-FR
        language = "fr-FR";
      }
      // set the language in the session
      httpContext.Session["lang"] = language;
      // Set the thread's culture            
      Thread.CurrentThread.CurrentCulture = new System.Globalization.CultureInfo(language);
      Thread.CurrentThread.CurrentUICulture = Thread.CurrentThread.CurrentCulture;
    }
  }
}

    • línea 7: [I18NController] deriva de la clase [Controller];
    • línea 7: la clase se declara [abstracta] para impedir la instanciación directa: sólo puede derivarse para ser utilizada;
    • línea 9: el constructor de la clase se ejecutará cada vez que se instancie un controlador derivado de [I18NController];
    • línea 12: recuperamos el contexto de la petición HTTP que está siendo procesada por el controlador;
    • línea 15: suponemos que el idioma se establece mediante un parámetro [lang] que se puede encontrar en varias ubicaciones. Buscamos en el siguiente orden:
      • línea 15: en los parámetros URL [?lang=es-US],
      • línea 19: en los parámetros publicados [lang=de],
      • línea 24: en la sesión del usuario,
      • línea 29: en las preferencias de idioma enviadas por el cliente HTTP,
      • línea 26: si no se encuentra nada, la configuración regional se establece en [fr-FR];
    • línea 37: almacenamos la configuración regional en la sesión. Aquí es donde se recuperará para peticiones posteriores. El usuario puede cambiarla incluyéndola en los parámetros de una petición GET o POST;
    • líneas 39-40: establecemos la configuración regional de la vista que se mostrará una vez procesada la solicitud actual.

    Un archivo de recursos es un diccionario que contiene claves y valores asociados a esas claves. Introduzca la clave en [1], el valor en [2] y el ámbito del recurso en [3]. Para que estos recursos sean legibles, deben tener la extensión [Público] alcance. Volvamos a la línea

  public abstract class I18NController : Controller
  {
    public I18NController()
    {
      // retrieve the context of the current request
      HttpContext httpContext = System.Web.HttpContext.Current;
      // check the request for the [lang] parameter
      // search for it in the URL parameters
      string language = httpContext.Request.QueryString["lang"];
      if (language == null)
      {
        // look for it in the posted parameters
        language = httpContext.Request.Form["lang"];
      }
      if (language == null)
      {
        // look for it in the user's session
        language = httpContext.Session["lang"] as string;
      }
      if (language == null)
      {
        // First parameter of the HTTP AcceptLanguages header
        language = httpContext.Request.UserLanguages[0];
      }
      if (language == null)
      {
        // culture fr-FR
        language = "fr-FR";
      }
      // set the language in the session
      httpContext.Session["lang"] = language;
      // Set the thread's culture            
      Thread.CurrentThread.CurrentCulture = new CultureInfo(language);
      Thread.CurrentThread.CurrentUICulture = Thread.CurrentThread.CurrentCulture;
}
