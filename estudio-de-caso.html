    9.5. Método de cálculo del salario de un cuidador de niños

    A continuación le explicamos cómo se calcula el salario mensual de un cuidador de niños. Como ejemplo, utilizaremos el salario de la Sra. Marie Jouveinal, que trabajó 150 horas en 20 días durante el periodo de pago.

    Se tienen en cuenta los siguientes factores:
    [TOTALHOURS]: total de horas trabajadas en el mes
    [TOTALDAYS]: total de días trabajados en el mes
    [TOTALHOURS]=150
    [TOTALDAYS] = 20
    El salario base del cuidador infantil se calcula mediante la siguiente fórmula:
    [BASESALARY] = ([TOTALHOURS] * [HOURLYRATE]) * (1 + [CPALLOWANCE] / 100)
    [BASESALARY]=(150*[2.1])*(1+0.15)= 362.25
    De este salario base deben deducirse una serie de cotizaciones a la Seguridad Social:
    Contribución social general y contribución a la amortización de la deuda social: [BASESALARY]*[CSGRDS/100]
    Cotización social general deducible: [BASESALARY]*[CSGD/100]
    Prestaciones de la Seguridad Social, viudedad y vejez: [BASESALARY]*[SECU/100]
    Pensión complementaria + AGPF + Seguro de desempleo: [BASESALARY]*[PENSION/100]
    CSGRDS: 12.64
    CSGD: 22.28
    Seguridad Social: 34,02
    Pensión: 28,55
    Cotizaciones totales a la Seguridad Social:
    [SOCIALCONTRIBUTIONS] = [BASESALARY] * (CSGRDS + CSGD + SECU + RETIREMENT) / 100
    [SOCIALCONTRIBUTIONS]=97.48
    Además, la cuidadora de niños tiene derecho a una indemnización diaria y a una indemnización por comida por cada día trabajado. Por tanto, percibe las siguientes indemnizaciones:
    [Allowances]=[TOTALDAYS]*(DAILYMAINTENANCE+DAILYMEAL)
    [ALLOWANCES]=104
    Al final, el salario neto que hay que pagar al cuidador de niños es el siguiente:
    [BASESALARY] - [SOCIALSECURITYCONTRIBUTIONS] + [ALLOWANCES]
    [NET SALARY]=368.77

    9.7.4. La clase [PamException]

    Creamos un tipo de excepción específico para nuestra aplicación. Se trata del siguiente tipo [PamException]:

    
using System;
 
namespace Pam.Business.Entities
{
  // exception class
  public class PamException : Exception
  {
 
    // error code
    public int Code { get; set; }
 
    // constructors
    public PamException()
    {
    }
 
    public PamException(int Code)
      : base()
    {
      this.Code = Code;
    }
 
    public PamException(string message, int Code)
      : base(message)
    {
      this.Code = Code;
    }
 
    public PamException(string message, Exception ex, int Code)
      : base(message, ex)
    {
      this.Code = Code;
    }
  }
}

namespace PamWeb.Infrastructure

  public class Static

    // List of error messages for an exception
    public static List<string> GetErrorsForException(Exception ex)
    {
      List<string> errors = new List<string>();
      while (ex != null)
      {
        errors.Add(ex.Message);
        ex = ex.InnerException;
      }
      return errors;
    }
 
    // list of error messages related to an invalid model
    public static List<string> GetErrorsForModel(ModelStateDictionary state)
    {
      List<string> errors = new List<string>();
      if (!status.IsValid)
      {
        foreach (ModelState modelState in state.Values)
        {
          foreach (ModelError error in modelState.Errors)
          {
            errors.Add(getErrorMessageFor(error));
          }
        }
      }
      return errors;
    }
 
    // the error message associated with an element of the action model
    static private string getErrorMessageFor(ModelError error)
    {
      if (error.ErrorMessage != null && error.ErrorMessage.Trim() != string.Empty)
      {
        return error.ErrorMessage;
      }
      if (error.Exception != null && error.Exception.InnerException == null && error.Exception.Message != string.Empty)
      {
        return error.Exception.Message;
      }
      if (error.Exception != null && error.Exception.InnerException != null && error.Exception.InnerException.Message != string.Empty)
      {
        return error.Exception.InnerException.Message;
      }
      return string.Empty;
    }

      • Un proceso P1 lee una fila L de la tabla [contribuciones] en el tiempo T1. La fila tiene un valor de columna [VERSIONING] de V1;
      • un proceso P2 lee la misma fila L de la tabla [contribuciones] en el tiempo T2. La fila tiene un valor de columna [VERSIONING] de V1 porque el proceso P1 aún no ha comprometido su modificación;
      • El proceso P1 modifica la fila L y consigna su cambio. La columna [VERSIONING] de la fila L pasa a ser V1+1 debido a la [INCR_VERSIONING_COTISATIONS] gatillo;
      • El proceso P2 hace lo mismo. EF5 lanza una excepción porque el proceso P2 tiene una fila con una columna [VERSIONING] que tiene el valor V1, que difiere del valor encontrado en la base de datos, que es V1+1. Una fila sólo puede ser modificada si tiene el mismo valor [VERSIONING] que en la base de datos. Una fila sólo puede modificarse si tiene el mismo valor [VERSIONING] que en la base de datos.

    Esto se llama optimista concurrencia control. Con EF5, un campo que desempeñe este papel debe tener el valor [ConcurrencyCheck] anotación.

function connection() {

    // retrieve the input form

        type: 'POST',
        dataType: 'html',
        beforeSend: function () {
            // loading indicator enabled
            loading.show();
        },
        success: function (data) {
            // display results
            content.html(data);
            // menu
            setMenu([lnkRunSimulation]);
        },
        error: function (jqXHR) {
            error2.html(jqXHR.responseText);
            error1.html(jqXHR.getAllResponseHeaders().replace(/\r\n/g, "<br/>").replace(/\r/g, "<br/>").replace(/\n/g, "<br/>"));
            error.show();
        },
        complete: function () {
            // wait signal turned off
            loading.hide();
        }
    });
}
