    6. Internacionalización de vistas

    Aquí abordaremos el tema de la internacionalización de vistas. Se trata de un tema complejo, y se puede encontrar una buena descripción del mismo en el siguiente artículo de Scott Hanselman:

    [http://www.hanselman.com/blog/GlobalizationInternationalizationAndLocalizationInASPNETMVC3JavaScriptAndJQueryPart1.aspx]

    En primer lugar, repasemos sus definiciones de los diversos términos relacionados con la internacionalización de vistas:

    Internacionalización (i18n)
    hacer que la aplicación sea compatible con diferentes idiomas y configuraciones regionales
    Localización (l10n)
    hacer que la aplicación sea compatible con un par específico de idioma y configuración regional
    Globalización
    la combinación de internacionalización y localización
    Idioma
    Idioma hablado: designado por un código ISO (fr: francés, es: español, en: inglés, ...)
    Configuración regional
    una variante del idioma – también designada por un código ISO (en_GB: inglés británico, en_US: inglés americano, ...)

    Abordemos el problema con un primer ejemplo.

    6.2. Gestión de una cultura

    El idioma de las vistas se controla mediante el objeto [Thread.CurrentThread.CurrentUICulture]. Para mostrar páginas en la cultura [fr-FR], escribimos:

    Thread.CurrentThread.CurrentUICulture=new CultureInfo("fr-FR");

    La localización (fechas, números, divisas, horas, etc.) se controla mediante el objeto [Thread.CurrentThread.CurrentCulture]. De forma similar a lo escrito anteriormente, escribimos:

    Thread.CurrentThread.CurrentCulture=new CultureInfo("fr-FR");

    Estas dos instrucciones podrían colocarse en el constructor de cada controlador de la aplicación. Sin embargo, quizá también queramos extraer este código que es común a todos los controladores. Adoptaremos este enfoque.

    Creamos dos nuevos controladores:

    • [I18NController] será la clase base para todos los controladores que utilicen la internacionalización;
    • [SecondController] es un controlador de ejemplo derivado de [I18NController].

    El código del controlador [I18NController] es el siguiente:

    
using System.Threading;
using System.Web;
using System.Web.Mvc;
 
namespace Exemples.Controllers
{
  public abstract class I18NController : Controller
  {
    public I18NController()
    {
      // retrieve the context of the current query
      HttpContext httpContext = HttpContext.Current;
      // examine the query for the [lang] parameter
      // look for it in the URL parameters
      string langue = httpContext.Request.QueryString["lang"];
      if (langue == null)
      {
        // look for it in the posted parameters
        langue = httpContext.Request.Form["lang"];
      }
      if (langue == null)
      {
        // search for it in the user's session
        langue = httpContext.Session["lang"] as string;
      }
      if (langue == null)
      {
        // 1st header parameter HTTP AcceptLanguages
        langue = httpContext.Request.UserLanguages[0];
      }
      if (langue == null)
      {
        // culture fr-FR
        langue = "fr-FR";
      }
      // put your tongue in session
      httpContext.Session["lang"] = langue;
      // changing thread cultures            
      Thread.CurrentThread.CurrentCulture = new System.Globalization.CultureInfo(langue);
      Thread.CurrentThread.CurrentUICulture = Thread.CurrentThread.CurrentCulture;
    }
  }
}

    • línea 7: [I18NController] deriva de la clase [Controller];
    • línea 7: la clase se declara [abstract] para impedir la instanciación directa: solo se puede derivar para su uso;
    • línea 9: el constructor de la clase se ejecutará cada vez que se instancie un controlador derivado de [I18NController];
    • línea 12: recuperamos el contexto de la solicitud HTTP que está procesando actualmente el controlador;
    • línea 15: suponemos que el idioma viene definido por un parámetro [lang] que puede encontrarse en varias ubicaciones. Buscamos en el siguiente orden:
      • línea 15: en los parámetros de la URL [?lang=en-US],
      • línea 19: en los parámetros enviados [lang=de],
      • línea 24: en la sesión del usuario,
      • línea 29: en las preferencias de idioma enviadas por el cliente HTTP,
      • línea 26: si no se encuentra nada, la configuración regional se establece en [fr-FR];
    • línea 37: almacenamos la configuración regional en la sesión. De ahí se recuperará para las solicitudes posteriores. El usuario puede cambiarla incluyéndola en los parámetros de una solicitud GET o POST;
    • líneas 39–40: establecemos la configuración regional para la vista que se mostrará una vez procesada la solicitud actual.

    Para crear un archivo de recursos, sigue estos pasos [1, 2, 3]:

    Esto crea el archivo de recursos [MyResources2.resx]. Al hacer doble clic en él, aparecerá la siguiente página:

    Un archivo de recursos es un diccionario que contiene claves y valores asociados a dichas claves. Introduzca la clave en [1], el valor en [2] y el ámbito del recurso en [3]. Para que estos recursos sean legibles, deben tener el ámbito [Public]. Volvamos a la línea:

    
    [Required(ErrorMessageResourceType = typeof(MyResources), ErrorMessageResourceName = "infoRequise")]

    • [ErrorMessageResourceType]: hace referencia al archivo de recursos. El parámetro [typeof] es el nombre del archivo. Este se convierte en una clase durante el proceso de compilación, y su código binario se incluye en el ensamblado del proyecto. Así que, en definitiva, [MyResources] es el nombre de la clase de recursos;
    • [ErrorMessageResourceName = "infoRequise"]: hace referencia a una clave del archivo de recursos. En definitiva, la línea significa que el mensaje de error que se mostrará es el valor del archivo [MyResources] asociado a la clave [infoRequise].

  {
    public I18NController()
    {
      // on récupère le contexte de la requête courante
      HttpContext httpContext = System.Web.HttpContext.Current;
      // on examine la requête à la recherche du paramètre [lang]
      // on le cherche dans les paramètres de l'URL
      string langue = httpContext.Request.QueryString["lang"];
      if (langue == null)
      {
        // on le cherche dans les paramètres postés
        langue = httpContext.Request.Form["lang"];
      }
      if (langue == null)
      {
        // on le cherche dans la session de l'utilisateur
        langue = httpContext.Session["lang"] as string;
      }
      if (langue == null)
      {
        // 1er paramètre de l'entête HTTP AcceptLanguages
        langue = httpContext.Request.UserLanguages[0];
      }
      if (langue == null)
      {
        // culture fr-FR
        langue = "fr-FR";
      }
      // on met la langue en session
      httpContext.Session["lang"] = langue;
      // on modifie les cultures du thread            
      Thread.CurrentThread.CurrentCulture = new CultureInfo(langue);
      Thread.CurrentThread.CurrentUICulture = Thread.CurrentThread.CurrentCulture;
}
