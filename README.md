# Introducción a ASP.NET MVC a través de ejemplos (noviembre de 2013)

Este repositorio contiene la versión **HTML** del documento *Introducción a ASP.NET MVC a través de ejemplos*, publicado originalmente en **noviembre de 2013**. 

El objetivo es presentar, a través de ejemplos, los conceptos clave de **ASP.NET MVC**, un marco web .NET basado en el **MVC (Modelo – Vista – Controlador)**. 

## Leer el documento en línea

* Sitio web del documento: [https://stahe.github.io/es-aspnetmvc-nov-2013/](https://stahe.github.io/es-aspnetmvc-nov-2013/)
## Requisitos previos

Para comprender los ejemplos se requieren pocos requisitos previos; basta con tener **conocimientos básicos de C#**.

* Adam Freeman, *Pro ASP.NET MVC 4* (Apress) — código fuente disponible: [http://www.apress.com/9781430242369](http://www.apress.com/9781430242369)
